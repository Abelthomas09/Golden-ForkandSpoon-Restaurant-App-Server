# Golden Fork and Spoon – Restaurant Application

Golden Fork and Spoon is a restaurant application designed to provide users with a convenient restaurant browsing and interaction experience.

The project follows a separate frontend and backend architecture, with two independent repositories.

## 🚀 Project Repositories

| Component | Repository |
|---|---|
| Backend Server | [Golden-ForkandSpoon-Restaurant-App-Server](https://github.com/Abelthomas09/Golden-ForkandSpoon-Restaurant-App-Server) |
| Frontend Application | [Golden-ForkandSpoon-Restaurant-App](https://github.com/Abelthomas09/Golden-ForkandSpoon-Restaurant-App) |

## 🏗️ Project Architecture

The application consists of two main components:

### 1. Backend Server
- Handles server-side application logic.
- Provides APIs for frontend communication.
- Manages data processing and database operations.
- Handles backend application functionality.

### 2. Frontend Application
- Provides the user interface.
- Handles user interactions.
- Communicates with the backend through APIs.
- Displays application data and content.

## ⚙️ Getting Started

### Clone the Backend Repository

```bash
git clone https://github.com/Abelthomas09/Golden-ForkandSpoon-Restaurant-App-Server.git
```

### Install Dependencies

```bash
cd Golden-ForkandSpoon-Restaurant-App-Server
npm install
```

Configure the required environment variables before starting the application.

Refer to `package.json` for available scripts and project-specific setup instructions.
